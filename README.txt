MM. SUTHAIS PORTFOLIO — QUICK START

1. Extract the ZIP.
2. Open index.html in Chrome or another browser.
3. To update content, open portfolio-data.js in VS Code.
4. Add projects inside the projects array. Set status to 'Completed' or 'Ongoing'.
5. To activate each project's 'View Project' button, fill live: 'https://example.com' in portfolio-data.js.
   Until you provide a URL, the button is visible but inactive. Each project has its own live field.
6. To add project image, place it in assets/ and set image: 'assets/my-project.jpg'.
7. For your portrait add portrait: 'assets/profile.jpg'.
8. For CV add cv: 'assets/MM-Suthais-CV.pdf'.
9. For LinkedIn / GitHub paste your full profile links in linkedin / github.
10. To publish: upload index.html, style.css, script.js, portfolio-data.js, and any assets folder to the SAME website directory.

This is a static frontend portfolio — no database, account, or paid platform needed.
The live project and social links are intentionally left blank until you add them.
Google Fonts needs internet; system fallback fonts work offline.
Do not put private keys, passwords or other secrets into public JS files.
